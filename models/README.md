# MODELS

In this folders there are models of cylinders and a folder with ```.stl``` models generated using Blender. 

The models is described by this configuration of files: 

```
scene_example/
	scene_example.xml
	meshes/
	scene_example.ply
```

Scenes implemented are 
- **Cylinder** of different radius and discretization. 
  For some configuration there is also a *long_long* model which is a 10Km length cylinder or a *short* which is a 4m length cylinder. 
- A simplified models of a **plane**.
